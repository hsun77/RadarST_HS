# Completed fixed-map scientific controls

The algorithm, models and final322 maps were not refitted or tuned. This directory
adds1000 matched complete-map controls per map, a matched molecular-order control,
all0–6-round policy prefixes, attribution of23961 actual selected physical shapes,
500 local-CFAR random regions per section/size and fixed-case membership audits.
See LOCKED_COMPLETION_PROTOCOL.md for seeds, aggregation and limitations.

Reproduction commands, from this directory on the archived local research setup:
python complete_controls.py generate --workers 8
python complete_controls.py evaluate --workers 8
python complete_biology.py
python iteration_ablation.py generate --workers 4
python iteration_ablation.py evaluate --workers 4
python summarize_completion.py
python audit_figure4.py

Insert spaces between option names and values (--workers 8). Default paths point
to the full registered H/G research archive. These analysis scripts require that
archive, its reference registry, candidate pools and frozen spot-CFAR arrays;
the small prepared-state review example alone is not the full322-map dataset.
Large immutable dependencies and null-membership matrices are retained locally
under H:/RadarST_ValidationCompletion_20261105 with input/output hashes. This is
not an arbitrary-raw-data one-command frontend or independent biological validation.
Final objects have no initialization-channel field. Exact type/size/count/area
matching does not reproduce learned dynamic eligibility. Neither control chooses
a new policy. Development molecular-order3–5 mean is higher than RadarST;
matched molecular superiority is not established by the bootstrap intervals.
The historical30-point initialization parameter grid was not rerun for the final
conditional policy. Scientific images have not been regenerated by user request.
